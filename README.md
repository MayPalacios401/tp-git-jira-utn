## Escenario elegido
Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción
El proyecto analiza un dataset público de ventas utilizando Python, Git, GitHub y Jira.

Se calcularon:
- ventas totales
- venta máxima
- venta mínima

Además, se generó un gráfico con la evolución de ventas.

## Estructura del proyecto

- /datos → dataset CSV
- /scripts → script principal en Python
- /resultados → gráfico generado
- README.md → documentación del proyecto
